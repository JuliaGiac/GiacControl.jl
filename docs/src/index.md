# GiacControl.jl

Nonlinear control analysis with Giac.jl: Lie brackets, relative degree, Hurwitz conditions, equilibria, center manifolds and weak foci.

!!! note "Under construction"
    This package is being built as part of [JuliaGiac](https://juliagiac.github.io/).
    It will receive its functionality once [Giac.jl](https://juliagiac.github.io/Giac.jl/)
    exposes the public API it builds on.
